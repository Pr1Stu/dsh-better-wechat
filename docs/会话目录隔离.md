# 微信会话目录隔离

当前微信设置页没有会话目录隔离开关。微信 Host 仍兼容 `workspaces.json` 中已有的会话目录配置；本文只说明这一 Host 配置边界，不代表其他渠道支持该功能。

配置文件默认为 `<DSH_HOME>/integrations/dsh-weixin/workspaces.json`。插件启动时读取，手动修改后重启 DSH：

```json
{
  "conversationDirectory": {
    "enabled": true,
    "strategy": "per-conversation",
    "prefix": "conv-"
  },
  "conversationDirectories": {
    "<botId>": { "enabled": false }
  }
}
```

`conversationDirectory` 是默认值，`conversationDirectories` 可按 Bot ID 覆盖。省略策略和前缀时分别使用 `per-conversation` 和 `conv-`。开启后，新建 Session 会使用按私聊标识派生的工作目录；手动 `/workspace` 和 `/conv` 修改会被拒绝。已有 Session 不会搬迁，插件也不会删除旧目录。

如不确定现有 `workspaces.json` 是否包含此字段，请先备份再编辑。当前设置页不提供修改入口；修改后的配置会在 Host 启动时校验。
