# 微信命令

本文适用于微信私聊适配器。发送 `/help` 可查看机器人返回的本地化命令列表。命令使用纯文字，并遵循该机器人的访问策略。

## 会话

- `/new` 新建 Session。
- `/sessionlist` 或 `/sessions` 列出 Session；`/session <ID、序号或标题>` 将当前私聊绑定到指定 Session。
- `/ls` 或 `/list` 查看本私聊使用过的 Session；`/go <序号>`、`/prev`、`/next` 在列表中切换。
- `/drop <序号>` 只从本私聊列表移除记录，不会删除 Harness Session。
- `/title [新标题]` 查看或修改当前标题；`/title <序号> <新标题>` 重命名列表中的 Session。
- `/fork [标题]` 从当前 Session 创建分支；`/reset` 重置上下文但保留 Session ID。
- `/tail` 或 `/peek [序号] [条数]` 预览最近的用户与助手消息，不调用模型。
- `/history [条数]` 查看当前 Session 最近消息，最多五条。

会话列表和绑定按微信私聊隔离。切换绑定后，后续回复会发往当前绑定的 Session。

## 工作区与模型

- `/workspace [序号或绝对路径]` 切换机器人工作区；`/workspacelist` 列出工作区。`/ws`、`/wsl` 和 `/workspaces` 是别名。
- `/models`、`/model`、`/reasoninglist` 和 `/reasoning` 查看或更改 Session 的模型及推理等级。
- `/presetlist` 和 `/preset` 查看或更改机器人的 Agent Preset。
- `/plan [off 或说明]` 切换计划模式。`/goal [文本]` 查看或设置目标，并支持 `clear`、`edit`、`pause`、`resume` 操作。
- `/compact` 压缩较早上下文。`/clear` 清理当前上下文，同时保留 Session 绑定与历史。

## 任务控制

- `/stop` 停止当前任务；`/steer <文本>` 为运行中的任务补充纠偏。
- `/batch` 开始最多十条文字的批量输入；`/send` 提交，`/cancel` 丢弃。
- `/status` 检查微信与 Harness 连接；`/version` 查看插件版本；`/help` 显示命令。

若已配置 Jev 自动路由，命令不会进入自动判断。手动执行 `/new`、`/go`、`/prev` 或 `/next` 后，下一条普通消息也会跳过自动路由。
